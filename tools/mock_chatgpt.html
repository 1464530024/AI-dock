帮我写一个 Python 快排，并说明复杂度

下面是一个原地快排实现：

def qsort(a, lo, hi):
    if lo >= hi: return
    p = a[lo]
    i, j = lo, hi
    while i < j:
        while i < j and a[j] >= p: j -= 1
        a[i] = a[j]
        while i < j and a[i] <= p: i += 1
        a[j] = a[i]
    a[i] = p
    qsort(a, lo, i-1); qsort(a, i+1, hi)

要点：

  • 平均 O(nlogn)
  • 最坏 O(n^2)，退化为已排序输入
空间 O(logn)，来自递归栈。
