# 更新日志

版本号遵循 `主.次.修订`。APK 与仓库 tag 一一对应。

## v1.2.0 — 2026-11-17

三个新能力，全部真机验证。

### 新增

- **4 个海外助手**：ChatGPT、Gemini、Claude、Copilot。抽屉改为「国内助手 · 8」「国外助手 · 4」两组，共 12 个。LOGO 均为官方矢量原件（Simple Icons / svgl）渲染而来。
- **设置页 · 账号保险箱**：手动登记站点 / 账号 / 密码 / 备注，支持编辑与删除。密码以 **AES-256-GCM** 加密落盘，密钥存 **AndroidKeyStore** 且不可导出。
- **二次验证**：支持 **4 位 / 6 位数字**，自绘数字键盘（不唤起输入法）。点击「显示密码」必须先验证，明文显示 **60 秒**后自动回掩码。可手动关闭，但关闭与修改验证码本身都需先通过验证。
- **防暴力破解**：连错 **5 次锁定 30 秒**，锁定期间键盘置灰并倒计时；锁定状态持久化，重启 App 不会重置。
- **对话导出为 Markdown**：顶栏下载箭头（或 ⋮ → 导出对话），把当前对话导出为带标题、时间、消息数、角色分离、代码块语言标记的 `.md`。抽取走「站点适配器 → 通用启发式 → 整页兜底」三层降级，已适配 10 个站点。可保存到 `下载/AI dock/`、分享或复制。
- **加载遮罩**：切换助手时立刻覆盖，避免"标题已换、正文还是上一个站点"的错位；8 秒未加载给出慢网提示。
- **桌面版 / 移动版网页切换**（按站点记忆）、**清除本站数据**、**关于** 页。

### 修复

- 保存账号时崩溃：Keystore 不允许调用方自带 IV（`Caller-provided IV not permitted`），改由 Keystore 生成 IV 后回读。
- 锁定期间重新打开验证弹窗仍可输入：验证结果未回写内存快照。
- 导出的代码块缩进被压平（Python 代码不可运行）：消息级清洗误用了会压缩空白的通用清洗函数。
- 切换站点时正文与标题错位：加载遮罩提前到新文档首个像素可绘制时再揭。

### 变更

- 顶栏动作区改为 导出 / 刷新 / 更多（⋮）。
- 版本号 `versionCode 4` / `versionName 1.2.0`，签名与 1.1.x 一致，**可直接覆盖升级**。

## v1.1.1 — 2026-11-16

- 修复首次启动必崩：抽屉头部图标误用 `R.mipmap.ic_launcher`，在 API 26+ 命中 `<adaptive-icon>` XML，`painterResource` 无法加载。改用 `R.drawable.app_logo` 纯 PNG 副本。

## v1.0.0 — 2026-11-16
